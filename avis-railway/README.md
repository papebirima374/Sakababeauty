# Formulaire d'avis Sakaba Beauty — version Railway

Copie autonome de la page `/avis` (mêmes questions, même envoi par Web3Forms),
mise en ligne sur Railway le 20/11/2026 parce que le projet Vercel était en pause.

- Railway : projet **sakaba-avis**, dossier racine `/avis-railway`, commande `npm start`.
- Variable Railway : `WEB3FORMS_KEY` (la même clé que `NEXT_PUBLIC_WEB3FORMS_KEY` sur Vercel).
- Aucune dépendance à installer. Test local : `WEB3FORMS_KEY=... node server.mjs`.
- Toute retouche de `components/FormulaireAvis.tsx` doit être reportée dans `public/index.html`.
